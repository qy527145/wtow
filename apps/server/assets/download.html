wtow CLI

macOS / Linux

curl -fsSL __WTOW_BASE_URL__/install.sh | sh

二进制装到 ~/.local/bin/wtow。可用 WTOW_BIN_DIR 改目录。

Windows（PowerShell）

irm __WTOW_BASE_URL__/install.ps1 | iex

装到 %LOCALAPPDATA%\wtow\bin 并自动加入用户 PATH。

接入项目

令牌在项目设置页生成：

wtow login --base-url __WTOW_BASE_URL__ --project <slug> --token <token>
wtow skill install
